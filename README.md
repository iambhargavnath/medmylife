# MedMyLife – Patient Appointment Management App

A Flutter application for managing patient appointments with doctors.

## Tech Stack

- Flutter 3.47.5
- Dart 3.13.4
- Riverpod
- Dio
- Drift
- email_validator

## Requirements

- Flutter 3.47.5 or compatible version
- Dart 3.13.4 or compatible version
- Android Studio / Xcode depending on the target platform

## Assignment

This project is being developed as part of the Medmylife Flutter Developer Technical Assignment.
